# 安全須知與聲明

## 安全須知

這個程式會以你的身分啟動 AI agent,讓它們在你的電腦上讀寫檔案、執行指令。使用前請了解:

- **「自動」模式的節點不會逐次詢問**,檔案修改與一般指令會直接執行。
- **遠端操作預設關閉。** 開啟後只在 Tailscale 位址與本機迴路上聆聽;連線是 HTTP,經 Tailscale 時由它加密,勾選「同一個 Wi-Fi」的連線沒有加密。
- **配對的裝置權限很大。** 「完整」角色等同坐在電腦前;「操作」角色只要能對一個自動模式的節點下指令,實際上也能讓它在你的電腦上做任何事。只配對你完全信任的裝置。
- **節點互相呼叫與會議會用到被呼叫那一家的額度。** 呼叫方是自動模式時不會先問你。設定 `NEXUS_INTEROP=0` 可以關掉整個功能。
- **獨立工作區只隔離檔案,不是沙箱。**
- 安裝檔沒有程式碼簽章。

發現安全問題請開 issue,或直接聯絡維護者。
