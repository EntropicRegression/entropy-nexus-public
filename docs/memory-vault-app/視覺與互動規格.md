## 一、整體空間架構與視覺語言

1. **上下雙層垂直空間攝影機切換**
   * **上層（仰望天空）**：**節點休眠庫（3D 星圖 × FF 角色水晶英靈殿）**
   * **下層（俯瞰地面）**：**判例模式（暖光大圖書館卷宗室）**
   * **過場動效**：切換時以垂直世界位移（`translateY`）搭配輕微 3D 俯仰角（`perspective` + `rotateX`）與星塵掠過效果；畫面之間設「天窗傳送門」邊緣按鈕可雙向快速穿梭。

2. **Game UI 遊戲介面風格**
   * 放棄一般圓角網頁卡片，統一採用 **45° 斜切角外框（Chamfered Corners）＋ 內層極細雙描邊 ＋ 菱形／四芒星飾釘**。
   * **未選取自動收起**：兩模式的右側詳情欄在「未選取任何項目」時自動收起為寬度 0，讓主舞台（3D 星圖／大圖書館卷宗牆）全幅展開；點擊任一水晶／卷宗後展開，**再次點擊同項目、點擊空白背景或按 `✕` 按鈕即自動收起**。

## 二、模式一：判例模式（大圖書館卷宗室｜下層）

* **背景氛圍**：使用高精細圖書館插畫底圖（如《熵值樞紐・星象共研》）壓暗柔焦＋暖琥珀燭光暈影，營造深夜秘密書房氛圍。
* **頂部急件委託欄（蠟封標記）**：
  * 固定優先顯示 **`狀態: 未確認` 的對話草稿**（提供一鍵「確認收錄」按鈕）與 **`子類: 書籤` + `狀態: 未完`**。
* **卷宗卡片牆與熱度視覺化**：
  * 依分類篩選：全部、`cases` 判例、`子類: 決策`、`子類: 書籤`、`preferences`。
  * 讀取記憶庫根目錄 `.nexus-heat.json`，以 **3 格發光晶石輝度計量槽**（沉睡／餘溫／微溫／熾熱）呈現召回熱度，高熱度卡片發暖金微光，低熱度沉降變暗。
  * 卡片右下角蓋上 **`節點ID` 與 `參與節點ID` 對應之 Q 版頭像圓章**；點擊頭像直接仰望飛往星圖並選中該節點水晶。
* **右側卷宗詳情（客觀與溫度分離）**：
  * 上半部顯示標題、`取代: [[舊檔]]` 演化關係、一句話`摘要`與客觀事實正文（對應 `memory_read` 預設內容）。
  * 下半部獨立為暖色羊皮紙邊框的 **`## 回顧`** 感言區塊（僅供人與特定情境閱讀）。

## 三、模式二：節點休眠庫（3D 星圖水晶｜上層）

* **3D 空間舞台與操作**：
  * 節點與背景多層旋轉星盤皆配置於 **真實 3D `(x, y, z)` 座標空間**（依 Z 軸深度即時計算透視縮放、前後遮擋 `z-index` 與景深透明度）。
  * 支援 **滑鼠左鍵拖曳 360° 旋轉視角** 與 **滾輪縮放遠近**，**停在最後拖曳角度、不自動自轉**。
* **FF 風格角色水晶**：
  * 每個節點為懸浮多面體水晶＋底部發光召喚陣，內部半透明折射顯示角色立繪（現役節點讀 `.nexus-stats.json` 解析好的 `立繪路徑`；封存節點讀 `nodes/封存/_圖像/<節點ID>/` 快照）。
  * **合併規則**：同一個 `節點ID`（經「開啟舊 session」復原後再封存的多份檔案）**合併為同一顆水晶**。
  * 狀態標示：**現役（線上/休眠）**、**封存・可喚醒**（CLI 原始紀錄仍在）、**封存・純紀念**。
* **4 種連線類型即時篩選**：
  * 星圖右上角提供獨立開關，可自由顯示／隱藏：
    1. **經驗傳承**（金色實線，來自 `接回自: <封存路徑>`）
    2. **交辦協作**（青色虛線，來自 `.nexus-stats.json` `協作`）
    3. **會議同席**（紫羅蘭點線，來自 `.nexus-stats.json` `同席`）
    4. **同專案星座**（翠綠星軌線，依共同參與之 `專案ID`）
* **右側水晶詳情（僅顯示濃縮版，不塞完整逐字對話）**：
  * **RPG 角色銘牌**（職稱＋稱號＋立繪頭像框）＋ **任務完成率／一次驗收率發光屬性條** ＋ 累計任務數／判例數。
  * **第一行精華特長（80 字內）＋ 濃縮解題流程 ＋ `## 回顧` 感言**。
  * **關聯卷宗連結（`[[案號]]`）**：點擊直接俯衝回大圖書館並打開該份卷宗。
  * **跨 App 喚醒**：若 `.nexus-stats.json` 顯示 `可接回: true`，顯示「在主控台喚醒舊 Session」按鈕，點擊觸發 **`entropy-nexus://wake?node=<節點ID>`**（由主控台跳出確認視窗後再接回）。

## 四、檔案掃描與 Windows 跨進程安全約定

* 忽略記憶庫內所有 **`_` 開頭的附屬目錄**（如 `_圖像/`）與 **`*.tmp`** 暫存檔。
* 讀取 `.nexus-heat.json` 與 `.nexus-stats.json` 時一次讀完即關檔，若撞到寫入瞬間而解析失敗則保留上一份快取。
