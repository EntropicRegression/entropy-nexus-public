# 角色設定

「角色」是可以套用在節點上的一組設定,包括外觀(立繪、頭像)、個性(角色卡)和聲音(語音播報用的參考錄音)。同一個角色可以給好幾個節點用,它們共用同一份設定。

一個角色就是立繪資料夾裡的一個子資料夾,資料夾名稱就是角色名稱。

```
%APPDATA%\entropy-nexus\portraits\
└─ claude\                ← 角色名稱
   ├─ neutral.webp        立繪:平常(有立繪的話,這張必要)
   ├─ thinking.png        立繪:思考(選用,以下同)
   ├─ busy.png            立繪:忙碌
   ├─ asking.png          立繪:詢問(待授權、提問)
   ├─ troubled.png        立繪:困擾(出錯)
   ├─ asleep.png          立繪:休眠
   ├─ avatar.png          Q 版頭像(也接受 chibi_avatar.png)
   ├─ persona.md          角色卡(也接受 persona.txt)
   ├─ voice.wav           聲音:參考錄音
   ├─ voice.txt           聲音:參考錄音說的內容
   ├─ style.txt           聲音:語氣指令(選用)
   └─ clips\              聲音:固定語音(選用,見下文)
        ├─ done.wav
        └─ approval.wav …
```

所有檔案都是選用的。資料夾裡只要有立繪、角色卡、參考錄音或 `clips` 資料夾其中一種,就會出現在角色清單裡。

## 建立角色

1. 打開立繪資料夾。主控台「新增節點」面板的「角色」欄位旁邊有「資料夾」按鈕;「語音」面板裡也有「開啟角色資料夾」。
2. 新增一個子資料夾,用角色名稱命名。名稱不能含 `\ / : * ? " < > |` 這些字元。
3. 依需要放入下面各節的檔案。
4. 重新打開「新增節點」面板,就能在「角色」欄位選到。已經在用的節點,可以在對話視窗的「設定」裡換角色。

## 立繪與頭像

- **立繪**:檔名決定表情,支援 png、webp、jpg。建議直式、去背、高度 600 像素以上。缺少的表情會改用 `neutral`。
- **Q 版頭像**:`avatar.png`(也接受 `chibi_avatar.png`、webp、jpg)。打開頂部「顯示」小面板裡的「頭像」後,主面板會把頭像裁成六角形,畫在節點裡。建議用正方形的圖,臉放在中間偏上。
- 沒有立繪的角色會用內建的預設圖。

## 角色卡(個性)

角色卡是寫給 agent 看的身分設定,寫下這個角色的身分、說話風格和職責,上限 8000 字。

- **在主控台裡編輯**:新增節點時選了角色,或在對話視窗按「設定」,角色欄位下方會出現「角色卡」,可以直接檢視、撰寫和儲存。手機版在節點的「角色卡」按鈕。
- **自己寫檔案**:在角色資料夾放 `persona.md`。
- 改了角色卡之後,使用這個角色的節點,會在下一則指令前收到「主控台通知」,換成新的設定。

撰寫建議:

- 寫清楚身分、語氣、擅長什麼、做事的原則。可以參考現有角色,例如「基本資料、核心性格、說話風格、專長、行為準則」這樣分段。
- 如果不想讓 agent 在回覆裡描述動作,例如「輕抱書本」,請在角色卡裡明確寫出來。

## 聲音(語音播報)

語音播報(「語音」面板裡的「朗讀」)預設用 Windows 的系統語音。角色有自己的聲音時,播報會改用它。聲音有兩種來源,在「語音」面板的「**播報的聲音來源**」勾選和排順序:依序嘗試,第一個有聲音的就用它,都沒有時用系統語音。

| 來源 | 需要什麼 | 優點 | 限制 |
|---|---|---|---|
| 固定語音 | 角色資料夾的 `clips\` 放預先錄好的短句 | 不需要語音服務、沒有延遲、品質可以一條一條挑 | 念不出完成的摘要,只說固定的句子 |
| 本機語音合成 | 語音服務與 CosyVoice,加上角色的 `voice.wav` | 念出整句,包括完成的摘要 | 要顯示卡和安裝,第一次比較慢 |語音合成的安裝見 [`tools/voice-server/README.md`](../tools/voice-server/README.md);整體規劃見[語音模式規劃](語音模式規劃.md)。

### 固定語音

在角色資料夾裡建一個 `clips` 資料夾,依事件放短句的錄音:

| 檔名 | 什麼時候播 | 句子範例 |
|---|---|---|
| `done.wav` | 你交辦的回合完成 | 「任務完成了,請看一下結果。」 |
| `approval.wav` | 等你授權 | 「有個動作需要你授權。」 |
| `question.wav` | 有問題要問你 | 「我有問題想問你。」 |
| `failed.wav` | 出錯 | 「出了點問題,請看一下畫面。」 |
| `lost.wav`、`quota.wav` | 失聯、額度到達上限(選用,沒有時用 `failed.wav`) | 「連線中斷了。」「額度用完了,排隊的指令先暫停。」 |

- 支援 WAV 和 MP3。同一個事件可以放好幾條,檔名寫成 `done-2.wav`、`done-開心.mp3` 這樣,播報時隨機挑一條,聽起來比較不單調。每個檔案上限 5 MB。
- 固定語音不會念出節點名稱,靠角色的聲音分辨是誰。
- 只錄了部分事件也可以:沒有錄音的事件會改用下一個來源(例如本機語音合成或系統語音)。
- 錄音可以用任何方式產生:自己錄、用 BreezyVoice 或 Qwen3-TTS 預先合成(慢沒關係,只要做一次),或用雲端服務的語音設計功能。來源一樣要遵守下面的「聲音的使用規範」。
- 放好檔案後,「語音」面板會列出各角色錄了哪些事件,點一下可以試聽。

### 在主控台裡設定(建議)

角色卡下方有一個綠框的「**聲音**」區塊,新增節點面板和對話視窗的「設定」裡都看得到。

| 按鈕 | 作用 |
|---|---|
| 錄一段 | 用麥克風直接錄,最長 15 秒,再按一次停止。錄完會自動辨識錄音內容。 |
| 選擇 WAV 檔 | 從這台電腦選一個現有的錄音。 |
| 播放原音 | 聽參考錄音本身。 |
| 自動辨識內容 | 用語音辨識聽出錄音說了什麼,填進「錄音說的內容」。 |
| 試聽 | 用這個聲音念一句;要先啟用語音合成。 |
| 移除聲音 | 刪掉參考錄音和錄音內容,要按兩次才會刪。 |

填好「錄音說的內容」和「語氣指令」(選用)後,按「**儲存聲音**」。

### 自己放檔案

- `voice.wav`:參考錄音。必須是 **16-bit 的 WAV**,長度 2 到 30 秒,建議 3 到 10 秒;只有一個人說話,沒有背景音。
- `voice.txt`:錄音說的內容,存成 UTF-8。沒有的話,語音服務會在第一次播報前自動辨識。
- `style.txt`:語氣指令,例如「用活潑、甜美的語氣說」。有這個檔案時,改用 instruct 模式合成。

### 讓聲音念得對的重點

- **錄音內容一定要和錄音一字不差。** 差一兩個字,模仿出來的發音就可能整句亂掉。用其他工具生成的參考音,常常和原本給它的文字不一樣,請先播放確認,或用「自動辨識內容」再修正。
- **繁體字會先自動轉成簡體再交給 CosyVoice。** CosyVoice 2 主要用簡體中文訓練,直接給繁體字常被念成粵語腔。這個轉換由語音服務自動處理,需要 `opencc-python-reimplemented` 套件。
- 英文名字(例如節點名稱 Hagemi)的發音不太準。
- CosyVoice 的發音偏向大陸普通話,捲舌比較明顯;參考音的口音只能部分改善這一點。

### 沒有合適的錄音:用 Qwen3-TTS 捏一個聲音

如果不想用真人的聲音,可以用 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)(Apache-2.0)的 VoiceDesign 模型(`Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`),用文字描述生成一段參考音,再匯入角色。實測下來的經驗:

- **要念的文字給簡體。** 給繁體字時,生成的聲音會變成粵語。
- **描述用英文寫,結尾加上 `Speaks Mandarin Chinese with a soft Taiwanese accent.`**,口音會比中文描述好一點。
- **描述會影響音高。** 寫「cheerful、playful、bouncy」這類字,會把音調往上拉,容易變尖;想要低一點,就寫「low-medium pitch、mellow、alto」,活潑感改用節奏描述。年齡寫得越小,音調也會越高。
- 每個描述多生成幾段再挑,同一個描述每次的差異不小。
- 生成後用語音辨識確認內容,錄音內容填實際念出來的字。
- 例:

  ```
  A young woman's voice in her mid-twenties with a clear, light, slightly airy timbre at a medium-high pitch.
  She speaks gently and unhurriedly with crisp, precise articulation, sounding thoughtful, polite and bookish.
  Speaks Mandarin Chinese with a soft Taiwanese accent.
  ```

### 聲音的使用規範

只用自己錄的聲音、取得本人同意的聲音,或像上面那樣用文字描述生成的原創聲音。不要用真人、配音員或動畫、遊戲角色的錄音片段,描述裡也不要寫「像某某角色」。
