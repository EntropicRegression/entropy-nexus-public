2. 使用者**不能**在會議室插話或結束會議，會議只由主持節點控制;會議室的對話框是唯讀的。
3. 同時有好幾場會議時，**各開一個**會議室。
4. 會議結束後，會議室**立刻消失**,要回看就到記憶庫查會議紀錄。


**已定案(2026-11-22 使用者決定)**:
- 會議紀錄每場**自動**存進記憶庫，不需要使用者按鈕。
- 存進去時是 `狀態: 未確認`,和記憶草稿一樣，使用者在記憶庫確認之前，任何節點都查不到。
- 確認後**可以引用**:總管和節點可以用 `memory_search`、`memory_read` 查到會議紀錄。開會或交辦時可以引用過去的討論，引用格式沿用 `[[...]]`。

**和 2-2 協作流程的關係**:第二版的「各自提案 → 開會收斂」流程，會議那一步可以直接用會議室顯示。
